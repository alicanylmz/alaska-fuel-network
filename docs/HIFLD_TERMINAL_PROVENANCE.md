# Former HIFLD Petroleum Terminals layer

The terminal source is an Alaska extract of the former U.S. Department of
Homeland Security HIFLD Petroleum Terminals layer. The preserved 73-row file
contains terminal identifiers, status, type, commodity, storage capacity,
modal indicators, and product flags:

`data/raw/hifld_petroleum_terminals/dist_final_data_raw.csv`

SHA-256:
`93da875c5de44d01f84e7e46545464342b867b6cfe80bb73b45ab58ac1c301a7`

HIFLD Open was discontinued on August 26, 2025, and the former public service
is no longer a stable download source. The repository therefore preserves the
exact Alaska snapshot used in the study and cites the surviving
[Data.gov catalog record](https://catalog.data.gov/dataset/petroleum-terminals)
and [HIFLD Open transition notice](https://www.napsgfoundation.org/hifld_open/).

The supplementary EIA-815 GeoJSON contains names and approximate locations but
not the capacity, status, type, modal, or product fields used here. It is a
cross-check rather than the terminal-data source.
